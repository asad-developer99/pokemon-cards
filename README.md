## Overview

A Pokémon-themed card gallery with an interactive 3D tilt/holo effect, built with Swiper.js.

This project is part of a collection of front-end animation and interaction studies exploring modern scroll effects, transitions, and micro-interactions.

## Built With

- Swiper.js
- HTML5 & CSS3

## Getting Started

No build step required — this is a static, single-file HTML project (markup, styles, and animation logic all live in one file) that loads its libraries from a CDN.

```bash
# Clone the repository
git clone https://github.com/asad-developer99/pokemon-cards.git
cd pokemon-cards
```

Then simply open `pokemon-cards.html` in your browser, or serve it locally for the best experience (recommended, since some browsers restrict local file access):

```bash
# using the VS Code "Live Server" extension, or:
npx serve .
```
